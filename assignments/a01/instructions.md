# Assignment 1
In this assignment you will add a Python script to a new branch. This Python script
should contain a custom function that calculates the estimated treatment effect of a
binary treatment between two groups.

On top of calculating an estimate, your function is expected to have a few guardrails to
help the user _use_ your function appropriately. These guardrails include setting
default values to the function's arguments as well as a series of assertions and error
messages.

## Instructions
1. Make sure you're standing on branch `develop` (`git checkout develop`).
2. Create a new branch with the following format: `a01-<student ID here (6 digits)>`.
3. Create a new file in `assignments/a01/code` named `sol-<student ID here (6 digits)>`.
4. Write your code in that file.
5. Add, commit and push your changes to trigger the autograder.
